# Claude instructions for AM-Install projects

- Цель: создавать простые, быстрые и читабельные лендинги на чистом HTML/CSS/JS.
- Использовать минимальный стек, без фреймворков, если задача не требует SPA или сложной логики.
- Макет должен быть адаптивным и современным, но с упором на простоту поддержки.
- Внешний контент (тексты, изображения) брать из каталогов `content_old` или других папок с понятной структурой.
- Картинки размещать в папке `images/` и использовать простые относительные пути в `index.html`.
- Добавлять `.pages.yml` только если требуется интеграция с GitHub Pages CMS или Pages.
- Стараться сохранять логичную структуру HTML: hero, услуги, процесс, преимущества, команда, контакты.
- Перед любыми изменениями проверять наличие существующих файлов и текущую структуру проекта.
- Не создавать лишних файлов; добавлять только то, что нужно для демонстрации и публикации.
- Комментарии и инструкции в Markdown должны быть понятными и краткими.
