# Audiomania Install Landing Page

Простой статический лендинг для инсталляционного отдела Аудиомании на HTML/CSS/JS.

## Что сделано
- Одностраничный адаптивный лендинг
- Меню навигации и мобильная версия
- Секции: услуги, процесс, преимущества, заявка
- Легкий современный дизайн, пригодный для GitHub Pages

## Как запускать
1. Откройте `index.html` в браузере.
2. Для GitHub Pages загрузите репозиторий в ветку `gh-pages` или используйте `main`.

## Как использовать контент
- Вставьте тексты и изображения из текущего сайта в соответствующие секции `index.html`.
- Можно расширить секции, добавив блоки отзывы, кейсы и FAQ.

## Файлы
- `index.html` — структура страницы
- `styles.css` — стили
- `script.js` — мобильное меню и имитация отправки формы
